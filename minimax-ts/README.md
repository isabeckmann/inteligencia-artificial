# Minimax em TypeScript

- `src/minimax.ts`: minimax genérico (`Jogo<E, M>`), poda alfa-beta opcional e `melhorMovimento`.
- `src/velha.ts`: jogo da velha que implementa a interface (mesmas 4 funções do molde original).
- `src/main.ts`: demonstração (árvore do material, custo com/sem poda, partida IA x IA).

## Como rodar
```
npm install
npm start
```
